# Public reproduction scope

This repository retains V7.1 scientific material while removing redundant historical presentation copies. Publishing support and explanatory text are maintained separately from the scientific engine and frozen evidence. No repair acquisition, method, dataset, training or sealed-test evaluation is added by repository cleanup.

## Included checks

The first-party engine, independent exact-distribution evaluator, fixed configurations, finite correctness fixtures, scalar evidence, six-figure programs, bilingual website and historical synthetic / DBLP saved-answer replay are included. Commands are listed in [README.md](README.md#finite-verification).

The public evidence validator checks exact control arithmetic and scalar same-pool identities. Figure checks compare complete numerical projection JSON and input provenance. Linux and Windows may render different PDF / SVG bytes; identical projected values do not imply identical binary rendering. Site checks establish local asset availability and integrity, not remote deployment success.

Historical V5 replay uses its own preserved engine and original iteration-order semantics. It refuses unrecorded queries, never obtains answers from evaluator gold, and checks complete candidate/action/partition/cost traces. The permitted replay bundles cover constructed synthetic inputs and pseudonymized DBLP data. Their source files and data hashes must remain unchanged.

## Limits and unavailable evidence

WDC is aggregate-only. Public tables cannot revalidate private pair identities, reconstruct its graphs or independently rebuild all V6 candidate pools. Full historical recomputation still requires the original private handoff and its declared external frozen assets; the public repository is not a substitute for them. Native TransClean / GraphCR reproductions remain incomplete.

Known-law controls are constructed examples, not representative observations or external validation. Twenty small-graph worlds are dependent outcomes of three fixed laws; the hundred-edge case is analytic, not a 2^100-world enumeration. A natural single-reference hindsight gap is not an identified expected regret or expected error rate.

V5's 21 external slots remain gate-stopped; V6's distinct 21 ALASKA Camera slots remain unstarted because the inspected official download was unavailable. Historical 42 unrun comparisons, timeouts and other negative evidence remain recorded. Repository publication neither retries nor replaces them.

## Historical inventories and current integrity

[provenance/archive_manifests/](provenance/archive_manifests/) retains `HISTORICAL_V5_MANIFEST.json`, `HISTORICAL_V6_MANIFEST.json`, `HISTORICAL_V7_MANIFEST.json` and `V7_1_DELIVERED_MANIFEST.json`. These describe the original archival releases. Paths in an archival manifest may refer to a former layout or a duplicate presentation file removed from this repository; an archival manifest is not a claim that every old file is present in the current checkout.

The current release manifest and release checker cover the cleaned checkout. Cleanup records distinguish retained scientific sources and replay dependencies from omitted duplicate websites, figures, documentation and old package inventories. Original local research ZIPs are preserved outside the public repository; they are not nested inside this checkout.

## Verification scopes

- Research-workspace tests cover the full original development environment.
- Public finite tests and exact scalar checks cover only their included interfaces and fixtures.
- Saved-answer replay checks recorded trajectories without new oracle answers.
- Clean extraction checks archive integrity using its documented installed runtime; it is not automatically a fresh operating system.
- Remote Actions installs the declared runtime and runs the public finite pipeline. Pages deployment depends on that pipeline; actual commit, run and live-asset verification are separate evidence.

No one scope is described as full historical recomputation. Local compilation or tests do not establish cloud Overleaf compilation, conference acceptance or successful remote deployment.
