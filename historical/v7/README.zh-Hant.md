# Cut Audit ER — V7

本地研究包加入固定的已知分布控制及同池評分記帳；保留 V6 全部自然結果。不新增 selector、校準器、自然資料 acquisition、下載或封存 test 存取，不保證會議接受。

三個小圖共有二十個合法分群世界，另有一個解析問題。它們分開展示事後資訊優勢與可精確計算的期望決策差距。精確 pair probabilities 只屬構造的機率律，不代表自然 matcher 已達完美校準。不能據此將自然資料的事後差距歸因為同一機制。

有限測試及製圖命令見英文 README。使用 Python 3.12、固定依賴、單執行緒及全新輸出目錄。合成 fixtures 是正確性測試，不作自然資料結果；歷史回放只用已付費答案，缺失便失敗，不從 gold 補答。

`evidence/` 保留 V6 彙總表並新增已知分布及同池成本表。所有 V6 公開檔案可依 `HISTORICAL_V6_MANIFEST.json` 核對。`historical/v5` 只保留一份，包括已允許公開的合成及 DBLP 回放。WDC 只公開彙總，無法重驗私人 pair 身分或重算全部歷史研究。
